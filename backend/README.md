# Ludis — Backend Services

This directory serves as the architectural boundary for future server-side persistence, API microservices, Python ML processing engines, and Supabase integration layers.

Currently, client-side dynamic demo state management and Next.js Route Handlers (`frontend/src/app/api/`) handle API proxying and session state.

When dedicated backend services (e.g. FastAPI / Express / Supabase migrations) are introduced, they will reside here in `/backend/src`.
